## Notice

- TDD driven
- Simplicity is always the top priority.
- Maintain good module coupling and re-usability.
- Container driven development.
- This is an experimental project and will not be released to production, so breaking changes are always allowed.

## Stack

- Language: Go
- Web Framework: Gin v1.12.0
- Database: support postgres 17-alpine and sqlite both
- Frontend Framework: antd-pro v6.0.3

## UI Style

WinUI 3 like, follow [Fluent Design](https://learn.microsoft.com/zh-cn/windows/apps/design/design-principles) Style.
